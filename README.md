# Chicken-Recipe-Finder
A simple and interactive recipe finder web application built using HTML, CSS, and JavaScript. The application fetches chicken recipes from TheMealDB API and allows users to explore meals, search recipes, manage their favourite meals, and view detailed cooking instructions.

Features
  Recipe Listing: Fetches and displays chicken recipes with meal images, names, categories, and country information.
  Search Recipes: Search recipes by meal name or country.
  Favourite Meals: Add recipes to your favourites and view them in a dedicated section.
  Remove Favourites: Remove meals from the favourites list.
  Recipe Details: View detailed information about a selected meal, including ingredients, measurements, cooking instructions, and a YouTube video link when available.
  Local Storage: Uses browser Local Storage to store recipe data and favourite meals.
  Interactive UI: Provides dedicated recipe cards, favourite meal cards, buttons, and a detailed recipe view.
  Styled Layout: Uses CSS Grid, Flexbox, gradients, shadows, and hover effects to create the interface

Technologies Used
  HTML5
  CSS3
  JavaScript (ES6+)
  Fetch API
  Async/Await
  Browser Local Storage
  TheMealDB API

API Used
  TheMealDB API
  The application uses TheMealDB to retrieve chicken recipes and their associated information.

Project Objective
The goal of this project is to practise JavaScript fundamentals through a practical web application, including API integration, asynchronous data fetching, dynamic HTML rendering, array methods, search and filter functionality, event handling, and Local Storage.
